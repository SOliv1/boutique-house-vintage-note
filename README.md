# Boutique House Vintage Notes

A standalone React and Vite site for the Boutique House Vintage Notes concept.
You can view the Vintage Notes site [HERE](https://boutique-house-vintage-note-production.up.railway.app/)

This site is intentionally separate from the live Boutique House Django shop. It
uses the Vintage Notes categories:

- Early Sketch Collection
- Timeless Dressing
- Worn & Loved
- Sketchbook
- The Wardrobe

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Railway

Deploy this repository as its own Railway project or service. The included
`railway.json` builds the React app and serves the Vite preview server.
